# Agent instructions

Before changing anything in this repository, read [AGENT_CONTEXT.md](AGENT_CONTEXT.md). It has
the project's rules (real TTS.ai calls cost money, the API key must never be exposed, and a push
to `main` deploys the live site), its conventions and its gotchas.

Then read [CURRENT_STATE.md](CURRENT_STATE.md) for what works and what doesn't, and
[NEXT_STEPS.md](NEXT_STEPS.md) for what to do next. When your work changes behavior or the
project's state, update those files too. The README lists every project doc.
